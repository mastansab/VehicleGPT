Problem Space

Why existing vehicle diagnostics fail drivers and technicians

Modern electronic control units broadcast thousands of sensor frames every second. Current diagnostic tools either compress this down to a single vague dashboard light or upload raw logs to distant cloud queues.

01 / LACK OF CONTEXT
Isolated Freeze-Frames
A standard diagnostic trouble code (like P0217 for engine overtemperature) only records the instant a threshold was crossed. It preserves zero temporal context about pump pressure or battery voltage over the preceding 20 minutes.
02 / CONNECTIVITY GAPS
Cloud Latency & Dead Zones
Cellular-linked telematics fail precisely when drivers need them most: in underground parking structures, remote rural highways, and mountainous mountain passes where emergency breakdowns occur.
03 / SILOED SUBSYSTEMS
Uncorrelated Causal Failures
Automotive ECUs operate independently. When an electric coolant pump drops flow by 18%, causing high-voltage battery cell temperature spikes that force inverter torque derating, no single controller correlates the chain.

Technical Questions

Frequently asked engineering questions

How does the system ensure safety isolation on the CAN bus? ↓
VehicleGPT attaches to the vehicle network through a physical receive-only data diode. The transceiver's transmit pin is physically tied high or disabled in silicon. The operating system socket is initialized with read-only flags (CAN_RAW_RECV_OWN_MSGS=0), mathematically preventing the inference stack from transmitting actuation frames to steering, braking, or powertrain controllers.
How does HealthEngine stay within the strict 2.0 GB RAM budget? ↓
The mathematical tracking core (HealthEngine) computes rolling statistics, slopes, and Z-scores using compact C-vectorized circular buffers taking less than 40 MB of RAM. The 4-bit quantized language model occupies 1.18 GB of memory, leaving ample headroom within a standard 2 GB edge allocation.
What happens when the driver asks general, non-car questions? ↓
The intent classifier detects general queries (e.g., "What is the capital of France?" or "Explain regenerative braking") and routes them directly to the on-device language model without appending vehicle sensor context. This avoids embarrassing hallucinations where a car tries to answer geography questions using battery voltage readings.

Safety Architecture

Zero-cloud privacy and functional safety isolation

Automotive systems cannot compromise on functional safety. VehicleGPT implements rigorous hardware and logical boundaries.

BOUNDARY 01
Receive-Only Data Diode
The CAN/CAN-FD physical transceiver has its transmit pin tied to logic high. The software layer cannot physically inject frames onto the bus, guaranteeing zero interference with ISO 26262 ASIL-D safety systems.
BOUNDARY 02
Zero Cloud Transmission
Every telemetry frame, statistical buffer, and language model weight resides exclusively in onboard storage. Telemetry, GPS coordinates, and diagnostic queries never leave the vehicle.
BOUNDARY 03
Encrypted Local Persistence
Historical trip logs are stored in AES-256 encrypted SQLite databases keyed to the vehicle's onboard Hardware Security Module (HSM).
